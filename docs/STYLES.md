# 🎨 Стили профиля

## Переключатель стилей (самый простой способ)

В `config/profile.json` есть строка:

```json
"style": "manga",
```

| Значение | Стиль |
|---|---|
| `"manga"` | 🖤 Манга: чёрно-белая страница с панелями, твоими артами, облачками, скринтоном и печатью-ханко |
| `"sakura-day"` | ☀️ Дневная сакура: небо, облака, зелёный холм, котики, пруд с карпами кои |

Поменяй значение → **Commit changes** → через 2–3 минуты робот перерисует всё: шапку, окно статуса, цитату,
подвал, разделители, карточки статистики, змейку, 3D-календарь, бейджи и навыки.
Твои тексты (подпись, снаряжение, навыки, соцсети) при этом **не теряются** — они общие для всех стилей.

Цвета виджетов каждого стиля лежат в `config/styles/<стиль>.json`, а рисунки — в
`scripts/anime_profile/styles/` (по одному файлу на стиль).

### Картинки для стиля манги

Стиль манги вклеивает в панели картинки из папки `assets/images/` (переводит их в ч/б и уменьшает).
Какая картинка где — задаётся в `config/profile.json` → `images`:

| Ключ | Где показывается |
|---|---|
| `header_left` | шапка, большая панель слева |
| `header_right` | шапка, панель справа |
| `status` | портрет в окне статуса |
| `quote` | персонаж, который «говорит» цитату дня |
| `footer` | подвал, панель слева |

Чтобы поменять картинку: загрузи файл в `assets/images/` (**Add file → Upload files**) и впиши его путь
в нужный ключ, например `"status": "assets/images/my-cat.png"`. Лучше брать квадратные картинки.
Если лицо обрезается, можно указать, какой частью прижимать картинку:
`"status": {"path": "assets/images/my-cat.png", "align": "xMidYMin"}` (`xMidYMin` — по верху,
`xMidYMax` — по низу, `xMinYMid` — по левому краю).

Если арт чужой — укажи автора в `config/profile.json` → `credits`, подпись появится под счётчиком просмотров.

## Сохранённые «закладки»

Каждый готовый вид профиля можно сохранить «закладкой» на точное состояние репозитория — **git-тегом** или
**коммитом**. Закладка никогда не меняется, поэтому к ней можно вернуться в любой момент.

| Закладка | Стиль | Посмотреть |
|---|---|---|
| тег `style-sakura-day` | ☀️ Дневная сакура: небо, облака, зелёный холм, котики, пруд с карпами кои | [открыть](https://github.com/wobuzhidaoq/wobuzhidaoq/tree/style-sakura-day) |
| коммит `ccabea7` | 🌙 Ночная сакура: тёмно-фиолетовое небо, луна, тории, котик на воротах | [открыть](https://github.com/wobuzhidaoq/wobuzhidaoq/tree/ccabea71081832e3e07080e92b44c026a94d51d6) |

По ссылке «открыть» GitHub показывает README ровно таким, каким он был в этом стиле.
Архив со всеми файлами стиля можно скачать на странице **Tags**:
https://github.com/wobuzhidaoq/wobuzhidaoq/tags

## Как сохранить стиль самому (одной кнопкой)

1. Вкладка **Actions** → слева **💾 Сохранить стиль** → справа **Run workflow**.
2. В поле **Название стиля** впиши название латиницей, например `cyberpunk`. Остальное можно не трогать —
   сохранится то, что сейчас в `main` (то есть то, что видно на профиле).
3. Нажми зелёную **Run workflow**. Через ~20 секунд появится тег `style-cyberpunk` — он сразу виден на странице
   **Tags**. Добавь его в таблицу выше, чтобы не забыть.

> Робот сохраняет только то, у чего файлы в `.github/workflows` такие же, как сейчас в `main`
> (так GitHub защищает репозиторий). Поэтому сохраняй стиль, пока он в `main`, — то есть сразу, как он понравился.

## Как безопасно попробовать новый стиль

1. Новый стиль делается **в отдельной ветке**, а не в `main`, поэтому профиль не меняется.
2. Смотришь превью. Нравится — сливаешь ветку в `main` через pull request. Не нравится — просто не сливаешь.
3. Понравился и его тоже хочешь сохранить — сохрани его кнопкой «💾 Сохранить стиль».

## Как вернуть сохранённый стиль

**Проще всего:** попроси Claude: «верни стиль `style-sakura-day`» (или «верни ночной стиль, коммит `ccabea7`»).

**Если эксперимент слили через pull request:** открой этот pull request на GitHub →
внизу кнопка **Revert** → **Create pull request** → **Merge pull request**. Профиль вернётся к прошлому стилю.

**Через командную строку** (в склонированном репозитории):

```bash
git fetch --tags
git checkout main && git pull
git restore --source=style-sakura-day --staged --worktree :/   # или --source=ccabea7 для ночного стиля
git commit -m "Вернуть стиль sakura-day"
git push
```

После пуша робот в Actions сам пересоберёт статистику, окно статуса и остальные картинки (2–3 минуты).

> Твои личные правки (ник AniList, тексты, соцсети) хранятся в тех же файлах. При возврате по тегу
> они тоже откатятся к состоянию на момент тега — после возврата проверь `config/profile.json` и `README.md`.
